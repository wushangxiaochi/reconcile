# 解忧杂事掂 (Worry-Solving Shop)

一个基于中国传统文化玄学理论的情绪价值类网页应用，帮助用户释放不良情绪，获得心灵慰藉和行动指南。

## 应用特点

- 以传统玄学理论为基础，为用户提供心灵慰藉
- 优雅的用户界面，融合东西方美学
- 响应式设计，适配移动端和桌面端
- 中国传统文化元素的现代呈现

## 使用说明

1. **首页**：选择您关心的主题（可多选），或在补充栏中输入自定义内容
2. **聊天页**：通过与系统的对话，表达您的具体困扰
3. **功能互动**：系统会提供各种互动功能（如抽取卦象、查看详解等）
4. **解忧过程**：完整体验5个互动回合，获得针对性的情绪疏导和行动指南

## 技术实现

- HTML5, CSS3 (Flexbox/Grid布局)
- 纯JavaScript交互，无需框架
- 响应式设计
- Google Fonts 字体
- Font Awesome 图标库

## 本地运行

1. 克隆仓库到本地
2. 直接在浏览器中打开`index.html`文件
3. 无需安装任何依赖或启动服务器
